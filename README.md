# E資格 学び直しノート（非公式）

JDLA **E資格**（Deep Learning for ENGINEER）の出題範囲を、概念ごとに1ファイルで解き直していく学習ノート集です。
資格は取ったが手が動かなくなった人間が、**現行シラバスで学び直すために**書いています。入門者向けではありません。

- 読むだけなら **<https://terralien.net/learn/e-shikaku/>** が読みやすい形になっています（このリポジトリが正本）
- **間違いを見つけたら Issue か Pull Request をください。** それがこのリポジトリを公開している理由です
- 出典は**一次情報のみ**（原論文・公式ドキュメント・公式仕様）。他社の教材・問題集は参照も引用もしません
- 対象は現行シラバス **E2026#2〜**

## これは何ではないか

| ❌ | 理由 |
|---|---|
| 過去問・想定問題集 | 試験問題の再現は規約違反であり、著作物です。**1問も載せません** |
| JDLA シラバスの転載 | 項目名を参照して**自作の解説**を書いています。公式文書の本文は転記しません |
| 公式教材 | 非公式です。JDLA および認定プログラム提供各社とは無関係です |
| 合格保証 | ありません。**記述の正しさも保証しません**（だから修正を受け付けています） |

## 作り方（隠さずに書いておきます）

このノートは **LLM エージェントが初稿を書き、機械検証と人間の抜き取り監査を通して**公開しています。

```
概念台帳(ledger/concepts.json)  ← docs/phase0-ledger-brief.md で公式シラバスから作る
  → エージェントが一次情報を読んで初稿を書く
  → scripts/validate.py が機械検証（下記）
  → 人間が抜き取り監査
  → 公開
```

機械検証で見ているのは以下です。**通っていることと、内容が正しいことは別です。**

| 検査 | 内容 |
|---|---|
| frontmatter | 必須キー・slug とファイル名の一致・台帳への登録 |
| 出典 | `sources` が空でないこと・**許可された一次情報ドメインのみ**であること |
| 内部リンク | 未作成のページへリンクしていないこと |
| 視覚要素 | 全 H2 に表・囲み・想起チェックのいずれかがあること |
| 数式 | `$`/`$$` の対応が取れ、KaTeX がパースできること |
| コード | 掲載コードが**実際に実行できる**こと |
| 出典URL | （`--check-links` 時）リンク先が生きていること |

だから **人間の目が最後の砦です。** 気づいたことを投げてもらえると、そのぶん精度が上がります。

届いた報告は **AIエージェントが分類し、直せるものは自動で Pull Request になります**（判断が要るものだけ人間へ）。
その仕組みと、どこで人間に回るかは [docs/automation.md](docs/automation.md) に公開しています。
